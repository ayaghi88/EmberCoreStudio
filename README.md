# Ember Core Studio

**An elite software engineering and independent self-publishing launchpad powered by the Gemini API.**

Ember Core Studio is a high-performance web application designed for CEOs, visionaries, and independent authors. It provides a real-time, interactive scoping incubator to estimate full-stack software development projects and elite book layout/formatting campaigns, ensuring complete code ownership and 100% royalty retention.

---

## 🚀 Quick Start

Get your local development instance of Ember Core Studio up and running in seconds:

```bash
git clone https://github.com/ayaghi88/ember-core-studio.git && cd ember-core-studio
npm install
npm run dev
```

## 🛠️ Built With

Ember Core Studio leverages cutting-edge tools and frameworks to deliver a beautiful, high-performance responsive experience:

*   **Google AI Studio** — The premier prototyping environment for refining generative workflows and agent execution logic.
*   **Gemini API** — Powers intelligent real-time contract generation, dynamic scope estimations, and author linguistic optimization utilizing the high-speed `@google/genai` SDK.
*   **React 19** — Built using modern, declarative functional components and state-management paradigms.
*   **TypeScript** — Strictly typed codebase for robust error catching, enhanced IDE autocompletion, and zero runtime surprises.
*   **Vite 6** — Extremely fast development server with lightning-quick bundling.
*   **Tailwind CSS v4** — High-fidelity modern styling using native CSS-variable configuration and clean utility utilities.
*   **Motion** — Elegant fluid layout transformations, fade animations, and interactive drawer state transitions.
*   **Lucide React** — Crisp, clean, and modern vector icon library.
